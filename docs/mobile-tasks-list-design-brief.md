# 바자울 모바일 내 할 일 목록 v1 디자인 브리프

2026-10-06. 기존 Claude 작업 ‘바자울 전자결재 앱 디자인’에 **내 할 일 목록 v1**을 새 페이지로 추가한다. 현재 원본을 다시 읽고 기존 13개 페이지·보드·파일·메모를 보존한다. 직원 채팅 목록 v1·대화방 v1의 라이트/다크 색상, 간결한 헤더, 선형 아이콘과 글자 체계를 이어간다. 디자인에는 합성 자료만 사용한다. 앱 구현·검증·배포는 Codex가 담당한다.

## 목적과 범위

본인에게 배정된 할 일을 빠르게 확인하고, 기한이 지난 업무부터 처리하는 **목록 화면 하나**를 디자인한다. 현재 앱에 있는 등록 및 상세 화면으로의 진입은 유지한다. 등록 폼·상세·이력 화면 전체 재설계, 팀 업무, 타 직원 목록, 검색·정렬·일괄 처리·우선순위·알림 기능을 새로 넣는 작업은 아니다.

목록은 미완료·기한 초과·완료·전체·삭제됨의 다섯 상태를 제공한다. 기한 초과는 미완료에 포함되는 부분집합이다. 미완료 7건·기한 초과 2건을 합쳐 9건이라고 표시하지 않는다. 실제 응답에 없는 건수는 —로 표시한다.

## 화면 구성

**뒤로 → 내 할 일 / 새로고침·등록 → 미완료·기한 초과 요약 → 상태 선택 → 현재 목록·페이지 → 업무 행** 순서다. 하단 탭바는 없다. 기존 16px 바깥 여백, 4/8/12/16px 간격, 얇은 경계와 기존 색상 토큰을 따른다. 큰 소개문·히어로·커다란 카드·빈 공간 없이 일을 바로 볼 수 있게 한다.

기준 390×844에서 첫 업무 행을 글로벌 고정 헤더 제외 스크롤 영역의 첫 40% 안에 시작한다. 현재 약 20.5%로 이미 충족한다. 현재의 밀도를 유지하고 상태/날짜/행동을 더 명확히 한다. 헤더는 52px 안팎, 요약 두 개는 64px 안팎, 행은 84px 안팎을 출발점으로 삼되 큰 글자에는 높이가 자연스럽게 늘어나게 한다.

행은 제목 최대 두 줄, 상태·기한, 선택적인 회의명 한 줄을 보인다. 제목·내용 영역을 눌러 상세로 이동하고 별도 버튼으로 완료 처리한다. 미완료에는 ‘완료’, 완료에는 **‘완료 취소’**를 사용한다. 현재 ‘취소’는 취소 대상이 불명확하므로 바꾼다. 삭제됨에는 완료 버튼이 없다. 두 행동의 터치 영역을 겹치지 않는다. 제목이 잘려도 접근 이름에는 전체 제목을 제공한다.

기한 초과는 위험 색상과 텍스트, 오늘은 기존 강조색과 텍스트로 구분한다. 날짜는 YYYY-MM-DD, 기한 없음은 ‘기한 없음’이다. 완료·삭제는 중립적으로 표시한다. 색상만으로 상태를 구분하지 않는다. 페이지 정보는 모든 상태에서 같은 위치에 놓아 필터 변경 때 줄바꿈으로 목록이 불필요하게 흔들리지 않게 한다. 많은 페이지에는 기존 이전·다음 동작을 제공한다.

## 상태와 작업 안전

| 상태 | 화면과 행동 |
| --- | --- |
| 최초 조회 | 요약 —, 간결한 목록 로딩. 0건·빈 목록으로 오해시키지 않는다. |
| 정상 목록 | 확인된 건수·현재 필터·페이지·실제 업무를 표시한다. |
| 빈 결과 | 확인된 0건 및 필터별 짧은 안내. 미완료는 등록으로 진입할 수 있다. |
| 새로고침 | 중복 새로고침을 막고 진행 상태를 표시한다. 기존 목록이 있다면 갱신 상태를 함께 표시한다. |
| 연결/서버 조회 실패 | 오류·‘다시 시도’. 이전 목록을 남길 때는 조회 실패가 분명해야 한다. 임의 성공/0건을 만들지 않는다. |
| 접근 거절/목록 없음 | 이전 업무·건수·성공 안내를 즉시 제거한다. 짧은 오류와 조회 재시도만 제공한다. |
| 완료/완료 취소 처리 중 | 해당 행의 진행 표시, 중복 전송 차단. 필터·페이지·등록·다른 완료 처리는 잠시 비활성화한다. |
| 처리 성공 | 확인된 상태를 반영하고 최신 건수·순서를 재조회한다. 확인 전 건수는 —. |
| 성공 후 조회 실패 | 처리 성공 안내와 조회 오류를 함께 유지한다. 재시도는 목록 조회만 하며 완료를 다시 보내지 않는다. |
| 충돌/권한 변화 | 자동 덮어쓰기·반복 처리를 하지 않는다. ‘최신 목록 불러오기’ 후 다시 선택하도록 한다. |
| 확정적인 처리 실패 | 입력/대상 상태를 유지한다. 기존 재시도는 원래 대상·동작을 재시도한다. |
| 화면 복귀·계정 변경 | 이전 계정/화면의 업무를 숨기고 새로 조회한다. 늦은 이전 응답은 적용하지 않는다. |
| 로그인 만료 | 사적 목록을 비우고 기존 로그인 흐름으로 이동하는 모의 동작. |

실제 비활성과 클릭 차단이 일치해야 한다. 권한 오류는 가림용 CSS가 아니라 DOM에서도 이전 업무를 제거한다. 목록에서 삭제·복구를 새로 제공하지 않는다.

## 합성 자료와 검수

기준일 2026-10-06. 검수용 사용자 이예시. 미완료 7·초과 2·완료 3·삭제 1·전체 10. 초과 ‘검수용 회의 자료 확인’(10-04), ‘공용 비품 목록 점검’(10-05), 오늘 ‘합성 일정 안내문 확인’(10-06), 긴 제목 ‘2026년_공용_자료_정리_및_다음_회의_준비를_위한_매우_긴_합성_할_일_제목_줄바꿈_검수’(10-07), 기한 없는 ‘검수용 파일 분류’. 선택적 회의명은 ‘검수용 회의’. 완료 제목은 ‘예시 회의록 정리’, 삭제 제목은 ‘이전 검수용 업무’. 모두 실업무와 관계없는 합성 자료다.

대표 390×844 라이트/다크, 360×800, 1366×768, 200% 상당 큰 글자에서 긴 한글·공백 없는 제목과 1,000,000건 같은 큰 숫자를 확인한다. 가로 넘침·버튼 겹침 없이 최소 44×44px 행동, 보이는 키보드 포커스, 일반 글자 대비 4.5:1·중요 경계 3:1이 필요하다. 큰 화면에서도 업무는 읽기 쉬운 폭에 정렬한다.

모의 상태·자료·테마·크기·글자 제어는 앱 밖 검토 패널에 둔다. 정상 미완료/초과/완료/삭제, 로딩·빈 목록·실패·권한 오류·완료 처리/충돌을 검수할 수 있게 한다. 프로토타입은 운영 서버나 실제 사용자 데이터에 연결하지 않는다. 모바일 OS·스크린리더·실제 계정 전환 검증과 웹 모의를 구분한다.

대표 PNG, 작동하는 합성 프로토타입, 편집 가능한 소스 **bajaul-tasks-list-v1-source.zip**, 검수 결과와 미확인 항목을 제공한다. 기존 페이지는 보존하고 ‘내 할 일 목록 v1’만 추가한다.
