200% 상당 확대에서 중첩 삭제 패널의 버튼이 패널 경계를 넘는 문제를 발견해 flex shrink를 적용했다. 재검수에서 취소 버튼/부모 폭 모두96px, 높이44px을 확인했다. 안전한 취소에 최초 포커스를 주고, 취소 후 원래 삭제 행동으로 복귀한다.

## 실제 앱 검수

주소 `http://127.0.0.1:8910/device`, API를 localhost 합성 서버로 강제 치환한 실제 Expo 웹 번들이다. 치환 경계를 찾지 못하면 번들을 차단하고, 알 수 없는 API는404로 차단한다. 실제 계정·개인정보·비밀번호·도장·운영 DB를 사용하지 않았다.

- **390×844 라이트:** 읽기 전용 계정 정보, 현재 도장·선택/삭제, 프로필 미등록·선택, 비밀번호 섹션 시작이 첫 화면에 보인다. 중복 큰 제목/소개 없음. `main-light.jpg`.
- **360×800 다크:** 긴 이름·부서·이메일이 줄바꿈하고 가로 넘침 없음. 도장은 흰 문서 표면. 미리보기 실패에도 현재 등록됨을 유지하며 재시도를 제공한다. `small-dark-long-preview-error.jpg`, `small-dark.jpg`.
- **200% 상당 확대:** CSS viewport180px을2배로 렌더한360×800. 긴 계정 정보, 삭제 확인의 세로 버튼, 비밀번호 첫 오류 입력/문구를 실제 렌더로 확인했다. 이것은 native fontScale 검증이 아니다. `large-200-*.jpg`.
- **이미지 선택/저장:** 실제 웹 파일 선택에서 합성 PNG를 선택했다. 현재 등록됨과 저장 전·파일명·크기를 분리한다. 저장 실패 후 두 이미지/선택 파일이 유지되며 재시도 성공 후 선택이 정리된다. 실제 picker 취소/선택 리소스 정리의 기존 코드와 테스트를 유지했다. `save-failed.jpg`.
- **삭제 확인/실패:** 계약의 대상·결과 문구를 표시한다. 취소 포커스 및 원래 행동 복귀, 등록 이미지 유지, 삭제 실패 후 확인/재시도, 성공 후 미등록/성공 문구를 확인했다. `delete-confirm.jpg`.
- **비밀번호 오류:** 보안 입력3개, 기존4~128자/현재와 다름/확인 일치 정책. 확인 불일치 때 세 입력을 보존하고 확인 입력에 포커스한다. 빈 제출 때 현재 입력에 포커스한다. 오류 후 각 입력을 수정하면 해당 오류만 해제한다. `password-error.jpg`, `large-200-password-error.jpg`.
- **중복 실행/재인증:** 합성 비밀번호 변경 POST1회와 Enter 연타2회를 실행했다. 처리 중 모든 변경/새로고침이 잠기고 POST는1회였다. 완료 시 이전 계정 화면/비밀번호가 제거되고 실제 session.signOut 경로로 로그인 화면과 완료 메시지가 표시됐다. fixture는 비밀번호 값·토큰을 로그에 저장하지 않는다.
- **세션 만료:** 계정 새로고침401에서 실제 session 경로로 로그인 화면에 복귀하고 이전 계정 정보·미리보기가 제거됐다. `session-expired.jpg`.
- **canChangePassword=false:** 입력과 제출을 렌더하지 않고 관리자 문의 안내만 표시한다.
- **조회 상태:** 최초 실패 시 변경 폼을 렌더하지 않고 재시도만 표시한다. 로딩은 최종 패널 구조를 따른다. 새로고침 실패는 이전 계정 정보와 입력을 보존하고 변경을 잠근다. `load-error.jpg`, `loading.jpg`, `refresh-failed.jpg`.

`layout-metrics.json`: 작은 다크/긴 정보/200% 검수에서 width=scrollWidth, 가로 넘치는 행동/제목0,44px 미만 행동0, 접근 가능한 h1 하나. 이전 화면의 탭바 DOM은 native-stack 아래 비활성 화면으로 남을 수 있으며 현재 화면에 표시되는 탭바는 없다. 텍스트·컨트롤은 기존 라이트/다크 HomeTheme 대비 토큰을 재사용한다.

## 자동 검증과 한계

계정/이미지/비밀번호/키보드 관련70개 테스트 통과. 모바일/루트 ESLint·TypeScript, diff whitespace 통과. 최종 Android/iOS/web3플랫폼 export 성공. 전체 단위 테스트2191개 통과, CI PostgreSQL 전용31개는 로컬에서 건너뜀. 로컬 Node22.21 모듈 로더 오류는 공식 Node22 최신 패치 런타임으로 분리했고, 전체 테스트의 DATABASE_URL 요구에는 운영 DB 대신 가상 localhost 주소를 제공했다. CI에서 DB·빌드·브라우저 검증을 별도로 완료해야 한다.

API·이미지 픽커·세션 계약은 유지한다. 계정 조회 중에도 변경을 잠가 최신 확인과 변경이 경쟁하지 않게 했다. 현재/선택 이미지 리소스 해제, 세션 경계, 응답 순서 guard는 유지한다. 화면 이탈이 이미 서버에 도착한 변경을 취소한다고 주장하지 않는다.

네이티브 iOS/Android Safe Area·키보드·fontScale·OS 파일 선택·VoiceOver/TalkBack은 실기기 검증 범위 밖이다. 웹 관리자1366×768은 변경 대상이 아니다. 배포 결과는 별도의 릴리스 기록에서 확인한다.
