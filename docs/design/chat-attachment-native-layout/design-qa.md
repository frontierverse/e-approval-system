# 채팅 첨부 카드 레이아웃 검수 — 2026-10-06

파일만 전송한 모바일 메시지에서 파일명이 사라지고 파일 작업 버튼이 카드 밖으로 내려와 시간과 겹치는 현상을 수정했다. 원인은 첨부 말풍선의 자동 폭과 `flex: 1`인 파일명 행의 조합이었다. 첨부가 있는 말풍선에 화면 폭 기준의 확정 폭을 주고, 파일 카드를 그 폭 안에 배치했다. 파일명은 자동 기준 폭을 유지하며 줄바꿈한다. 기존 파일 작업과 읽음 표시를 보존했다.

사용자 제공 실기기 사진은 로컬 진단에만 사용했다. 이 문서와 이미지의 사람·대화·파일은 독립적인 합성 자료다. 사진과 실제 대화는 저장소에 포함하지 않았다.

## 검수 결과

- 실제 앱 컴포넌트를 React Native 0.86의 vendored Yoga C++ 엔진으로 배치했다. 180/320/360/390/1366px, 글꼴 배율 1/2, 송수신, available/deleted/deleting, 짧은/긴 파일명, 파일 단독/본문 동반의 240개 조합을 통과했다. 동일 테스트에서 수정 전 소스는 폭 180px의 삭제된 파일 카드가 50px로 줄어드는 회귀를 재현했다.
- Expo 웹 화면을 390×844, 360×800, 1366×900, 라이트 390px, 200% 확대에서 캡처하고 직접 확인했다. 200%는 180px 논리 뷰포트를 2배 확대하는 검수 셸이다. 화면 밖 데이터는 대화 목록 스크롤로 접근한다.
- 각 화면의 첨부 3개 모두 파일명 폭이 양수이고 파일명·버튼이 카드 내부에 있다. 파일 작업 버튼은 최소 44×44px, 시간은 카드 아래 4px 간격이다. 가로 넘침은 없다. 390px의 파일 단독 카드 폭은 약 294px, 360px에서는 약 269px이다.
- 200%에서 키보드 Tab으로 긴 파일 작업 버튼에 이동하고 화면에 표시되는 포커스를 확인했다. HWP 파일 작업 패널을 열고 닫아 대화로 복귀했다. 다운로드·삭제·전송은 실행하지 않았다.
- 관련 채팅 회귀 검사 71개, 루트/모바일 린트·타입 검사, 운영 설정 검사, Android/iOS/web 공식 export를 통과했다. 앱 콘솔 오류 0개. 브라우저 확장 프로그램의 ethereum 주입 충돌 1건은 별도 기록했다.

## 확인 범위

Yoga 검사는 앱의 실제 레이아웃 엔진과 컴포넌트를 사용하지만 텍스트 측정은 합성 줄바꿈 모델이다. 웹 확대와 검수 셸의 Safe Area는 실기기 OS 큰 글꼴·실제 Safe Area 검사와 다르다. 물리 Android/iOS 기기의 폰트 렌더링·키보드·스크린리더와 OTA 적용 후 화면은 직접 확인하지 않았다. 파일 작업 패널은 스크롤 가능한 기존 화면이며 200%에서 모든 제어가 동시에 표시된다고 주장하지 않는다.
