## 4. 상호작용 — 48/48 PASS

### 구조·표시

- **idle:** ‘현재 버전 사용 중’과 ‘업데이트 확인’을 보여줍니다. ‘최신 버전입니다’ 같은 단정 문구는 어떤 상태에도 없습니다.
- **메인 값:** 앱 버전 1.0.5, 코드 demo10a1, 게시 2026. 10. 5. 오전 9:00:00, 적용 확인 오전 9:30:00, 최근 확인 시도 10. 6. 오전 2:30:00, 최근 다운로드 확인 10. 5. 오전 9:05:00 (한국시간).
- **노출하지 않는 항목:** 런타임·채널·전체 배포 ID·서버 주소·릴리스 노트·용량·남은 시간·스토어·자동 업데이트 설정·‘지금 재시작’.
- **코드 버전:** ID 앞 8자, 또는 ‘설치 파일에 포함된 기본 버전’, 또는 ‘확인 불가’로 표시합니다. 기록이 없거나 날짜가 잘못되면 ‘확인 기록 없음’이며, 가짜 시각을 만들지 않습니다.
- **시각 안내:** ‘실제 설치 시각과 다를 수 있습니다’와 ‘확인 시도에는 실패한 시도도 포함됩니다’를 함께 표시합니다.
- **키보드:** Tab 순서는 뒤로 → 주 행동이며, focus-visible 윤곽이 보입니다.

### 확인 → 다운로드 → 적용 대기

- **확인:** 연타해도 요청은 1건입니다. ‘확인 중…’ 동안 잠기고, 포커스는 상태 제목으로 이동합니다. 확인을 시도하는 즉시 최근 확인 시도 시각이 기록됩니다.
- **다운로드:** 새 업데이트가 있으면 이어서 다운로드합니다. 0% → 37% → ‘다운로드 100% · 마무리 중’으로 바뀌며, 100%만으로는 적용 대기가 되지 않습니다. progressbar 값은 0/37/100입니다. 다운로드 중 연타는 무시합니다.
- **진행률 null:** ‘업데이트 다운로드 중’으로 표시하고 숫자·막대·aria-valuenow를 넣지 않습니다. 0%는 0%로 표시해 미확인과 구분합니다.
- **ready:**
  - 지정 안내 문구를 그대로 보여주고, 확인·다운로드·재시작·종료 버튼은 없습니다.
  - 실행 중 코드·게시 시각·적용 확인 시각은 demo10a1 그대로이고, 최근 다운로드 확인 시각만 갱신됩니다.
  - 앱 버전은 1.0.5를 유지합니다.
- **모의 재실행:**
  - 적용 대기 상태에서 재실행하면 demo11b2가 실행 중 코드가 되고, 새 게시 시각과 새 적용 확인 시각이 생깁니다. 상태는 idle입니다.
  - 같은 코드로 다시 실행하면 첫 적용 확인 시각을 유지합니다.
- **새 업데이트 없음:** idle로 돌아가며 다운로드는 없습니다.

### 실패·재시도

- **확인 실패:** 안전한 오류 문구와 ‘업데이트 다시 확인’을 보여주고 오류로 포커스합니다. 다시 확인하면 확인 요청이 다시 나갑니다.
- **확인 중 다운로드 실패:**
  - ‘확인 또는 다운로드’ 오류 문구를 보여줍니다.
  - 다운로드 대상(새 업데이트 게시 시각)을 보존하고, ‘다운로드 다시 시도’와 ‘새 업데이트 다시 확인’을 제공합니다.
- **다운로드 다시 시도:** 확인이 아닌 다운로드로 실행합니다. 연타해도 1건이고, 처리 중에는 보조 행동을 숨깁니다. 성공하면 적용 대기가 됩니다.
- **available 상태에서 다운로드만 실패:** ‘다운로드를 완료하지 못했습니다’ 문구를 보여줍니다.
- **rollback:** 적용 대기 상태에서도 실행 중 코드는 그대로입니다. 재실행한 뒤에만 ‘설치 파일에 포함된 기본 버전’으로 바뀝니다.

### 경로·수명

- **뒤로 대상:**
  - 이전 화면이 있으면 그 화면(내 정보·로그인·홈)으로 갑니다.
  - 이력이 없으면 로그인 후는 내 정보, 로그인 전은 로그인으로 갑니다.
  - 로그인 전에도 같은 기기 상태를 보여주며 계정 정보는 없습니다.
- **처리 중 뒤로:** 확인·다운로드를 취소하지 않습니다. 다시 열면 이탈 중 진행된 결과(적용 대기)가 반영되고, 중복 요청은 없습니다.
- **다운로드 중 재실행:** 이전 실행의 늦은 응답은 무시합니다. 적용 대기나 다운로드 기록이 생기지 않고, 코드도 같은 코드입니다.
- **기기 기록 저장 실패:**
  - 지정 문구로 알리지만 확인→다운로드→적용 대기는 그대로 진행되고, 이번 실행의 값도 표시합니다.
  - 기술 오류·저장소 이름은 표시하지 않습니다.
- **비상 복구:** 현재 적용 섹션에 지정 안내를 표시하고, 기본 버전을 보여주며, 업데이트 확인을 계속 쓸 수 있습니다. 최신으로 단정하지 않습니다.
- **disabled:** 지정 제목·안내만 보여주며 실행 행동은 없습니다(뒤로만).

## 5. 시안에서 정한 점

- 상태별 짧은 보조 설명은 시안에서 정한 문구입니다. 예: ‘확인하는 동안에도 다른 업무는 계속할 수 있어요’, ‘준비가 확인되면 적용 대기로 바뀌어요’.
- rollback 준비에서는 게시 시각 대신 ‘준비된 업데이트: 기본 버전으로 되돌리기’로 표시했습니다.
- 뒤로 이동 화면은 기존 화면 자리를 표시한 모의 상태입니다.
- 앱 업데이트 화면에서는 전역 업데이트 안내를 중복 표시하지 않습니다.
