# Claude Design 전달 바자울 모바일 계정·도장 설정 v1

디자인 요청 기준일 **2026-10-06 한국시간**, 운영 main **15c38b1030c51be76fc5377b23971891c65811a7 / PR #29**. 홈 v2·문서함 v1·문서 상세 v1·기안 작성 v1·받은결재 v1·알림 v1·내 정보 v1은 실제 앱과 Android·iOS 운영 OTA에 적용 및 배포 검증을 완료했다. 기존 Claude 작업 **바자울 전자결재 앱 디자인**에 여덟 번째 페이지 **계정·도장 설정 v1**을 추가한다.

## 목적과 범위

직원이 자기 계정 정보를 확인하고 결재 도장/서명·프로필 이미지를 안전하게 등록·교체·삭제하며 비밀번호를 변경하는 `/account` 자식 화면이다. **내 정보 → 계정·도장 설정**으로 들어오며 뒤로 가면 내 정보로 돌아간다. 내 정보 허브의 HomeTheme·Feather·간결한 그룹 표면을 이어간다. 완료한 일곱 페이지는 보존한다.

범위는 이 설정 화면과 그 이미지/비밀번호 상태다. 이름·부서·직급·이메일 편집, 계정 삭제, 기기 관리, 생체 인증, PIN, 2FA, 테마 설정, 이미지 자르기/그리기/서명 생성, 알림 설정, 앱 업데이트 상세를 발명하지 않는다. 이미지 선택은 **파일 선택**이며 카메라·사진 보관함 전용 권한 흐름을 추가하지 않는다.

Claude는 합성 자료로 모의 프로토타입과 편집용 소스를 만든다. 실제 로그인·비밀번호·직원/청소년 정보·도장 사진·운영 API·푸시·DB·앱 저장소·배포를 사용하거나 변경하지 않는다. 추가 폴더 접근이나 계정 권한을 요청하지 않는다. 실제 Expo 앱 구현과 배포는 Codex가 결과를 받아 별도로 처리한다.

첨부 01 브리프, 02 필수 UI/UX 기준, 03 최신 기능 계약, 04·05 실제 적용된 홈·내 정보 스타일, 06·07 현재 Expo 웹 계정 설정의 합성 기능 캡처다. 최신 계약을 우선한다. 06·07의 기존 남색 버튼·여백·헤더 높이는 기능 참고이며 새 시안은 04·05의 시각 언어를 따른다. 캡처의 원본/운영 계정·이미지·비밀번호는 없다.

## 화면 구성

**뒤로 + 계정·도장 설정**의 짧은 헤더와 접근 가능한 새로고침, **계정 정보 → 결재 도장/서명 → 프로필 이미지 → 비밀번호 변경** 순서다. 자식 스택 화면이므로 하단 전역 탭바를 새로 붙이지 않는다. OS 상태바를 장식으로 이중 생성하지 않는다. 기존 계정 정보라는 중복 큰 상단 제목을 줄이고 바로 계정 조회와 도장 설정을 읽게 한다. 헤더는 기존 52px 디자인을 시작점으로 쓰되 큰 글자에서 제목·뒤로·새로고침을 겹치거나 자르지 않는다.

폼의 정확성과 입력 접근성이 우선이다. 목록 화면의 첫 작업 40% 목표를 억지로 적용하지 않는다. 과도한 아바타·히어로·소개·새로운 업무 지표 없이 계정 정보와 도장 상태/행동을 첫 화면에서 파악하게 한다. 16px 외곽, 얇은 경계, 간결한 섹션, 최소 44px 행동 영역을 기본으로 하며 데이터/오류가 길면 자연스럽게 스크롤한다.

## 계정 조회

이름·부서·직급·이메일은 **읽기 전용**이다. 이메일 `null`이면 **미등록**. 계정의 권한/활성 상태/가입일/최근 접속은 화면 계약에 없다. 이름 첫 글자의 작은 표식을 쓰더라도 서버 프로필 사진과 혼동하지 않는다. 프로필 사진은 별도 이미지 섹션에서만 관리한다.

최초 로딩은 같은 구조의 간결한 상태로 보여준다. 첫 조회 실패는 오류와 다시 시도. 이전 조회가 성공한 뒤 새로고침 실패하면 마지막 계정 정보를 유지하면서 오류와 재시도를 보이고, 최신 상태를 확인할 때까지 변경 행동은 잠근다. 오류를 성공/미등록/비밀번호 변경 불가로 바꾸지 않는다. 이전 계정 정보는 계정 전환/로그아웃/401에서 제거한다.

## 이미지 등록·교체

도장/서명과 프로필의 동작은 같고 의미와 안내만 다르다. 등록된 이미지는 **현재 등록됨**, 새로 선택한 이미지는 **저장 전** 상태로 구분한다. 선택만으로 서버 등록 상태를 바꾸거나 저장 성공으로 표시하지 않는다. 등록 이미지와 선택 이미지가 함께 있어도 어떤 것이 적용 중인지 분명해야 한다.

**이미지 선택 → 선택 미리보기·파일명·크기 → 이미지 저장**. 선택된 파일이 있을 때 다른 이미지 선택과 선택 취소를 제공한다. 선택 취소는 미저장 선택만 버리며 기존 등록 이미지를 삭제하지 않는다. 파일 선택 창 취소는 기존 선택과 등록 이미지를 그대로 둔다. 저장 실패는 기존 등록 이미지와 선택을 유지하고 **이미지 저장 재시도**가 가능해야 한다. 저장 성공 응답 후 등록 미리보기를 갱신하고 선택을 해제한다. 낙관적으로 저장 성공을 만들지 않는다.

JPG·PNG·WEBP, 원본 **4MB 이하**, 서버 자동 압축 후 **2MB 이하**. 실제 형식과 확장자가 일치해야 한다. 도장은 **투명 배경 PNG 권장**. 도장 미리보기는 다크에서도 실제 흰 문서 바탕으로 잉크를 확인하되 제목·안내·행동은 다크 토큰을 쓴다. 등록 이미지 미리보기 로딩/실패는 계정 전체 오류와 분리하고 **미리보기 다시 시도**를 제공한다. 실패를 미등록으로 단정하지 않는다. 공개 URL·저장 키·인증 토큰·내부 파일 경로를 화면에 노출하지 않는다.

도장 미등록이면 ‘등록된 도장/서명 이미지가 없습니다.’, 프로필 미등록이면 ‘등록된 프로필 이미지가 없습니다.’. 도장 등록 목적은 결재에 사용할 도장 또는 서명. 프로필은 등록하지 않으면 이름 첫 글자가 기본 이미지로 표시된다는 기존 안내를 유지한다. 내 정보 허브가 실제 사진을 조회/표시한다는 새 계약은 만들지 않는다.

이미지 선택/저장/삭제나 비밀번호 변경이 실행 중이면 이 화면의 겹치는 변경·새로고침을 잠그고 작업 대상에 ‘선택 중… / 저장 중… / 삭제 중… / 변경 중…’를 표시한다. 한 번의 클릭/연타는 한 작업이다. 다른 계정이나 닫힌 화면에 늦은 성공/오류를 적용하지 않는다.

## 이미지 삭제

등록된 이미지가 있고 미저장 선택이 없을 때 **이미지 삭제**를 제공한다. 바로 삭제하지 않고 해당 이미지의 확인 상태를 보여준다. 확인 취소는 그대로 유지한다. 확인 중에는 같은 이미지 선택/저장 행동을 겹치게 실행하지 않는다.

- 도장: ‘등록된 결재 도장/서명 이미지를 삭제하시겠습니까? 다음 결재에는 기본 도장이 사용됩니다.’
- 프로필: ‘등록된 프로필 이미지를 삭제하시겠습니까? 이름 첫 글자가 기본 이미지로 표시됩니다.’
- 행동: **취소 / 삭제 확인**. 위험 색은 확인 행동에만 절제해서 쓴다.

삭제 성공 후에만 미등록과 완료 피드백으로 바꾼다. 삭제 실패는 등록 이미지와 확인 의도를 유지하고 오류/재시도를 제공한다. 계정·결재 문서 삭제가 아니다. 기존 인라인 확인을 유지하거나 접근 가능한 확인 모달로 바꿀 수 있으며, 모달은 최초 안전 행동 포커스·내부 이동·Escape/취소·실행 요소 복귀를 검토한다.

## 비밀번호 변경

`canChangePassword=true`일 때 현재 비밀번호·새 비밀번호·새 비밀번호 확인의 세 입력과 **비밀번호 변경**을 제공한다. 각 입력은 보안 입력이며 독립된 접근 이름과 오류를 가진다. 실제 사용자 비밀번호를 입력하거나 생성하지 않는다. 합성 데모값은 화면/검수 기록에서 실제 인증 정보와 구분한다.

새 비밀번호는 **4~128자**로 기존 웹/서버 정책을 유지한다. 현재 비밀번호와 달라야 하고 확인과 일치해야 한다. 새로운 대문자/숫자/특수문자 강제·복잡도 점수·주기 변경 규칙은 추가하지 않는다. 서버가 현재 비밀번호를 확인한다.

검증/통신 실패에서 세 입력을 보존하고 첫 오류 입력을 포커스한다. 해당 입력 수정 시 해당 오류를 해제하며 다른 입력 오류는 남긴다. 키보드 Next는 다음 입력, Done은 단일 변경 요청, 제출/중복 잠금 상태가 분명해야 한다. 가상 키보드가 현재 입력·오류·최종 행동을 가리지 않도록 스크롤을 검토한다.

변경 전에 **변경 후 모든 모바일 기기에서 다시 로그인해야 합니다**를 짧게 안내한다. 성공하면 세 입력을 지우고 현재 세션도 로그아웃하며 ‘비밀번호가 변경되었습니다. 새 비밀번호로 다시 로그인하세요.’와 모의 로그인 상태로 이동한다. 같은 화면에 오래 머무르는 성공 토스트나 이전 계정 화면 복귀를 만들지 않는다. 모든 기기의 실제 화면이 즉시 이동한다고 약속하지 않는다. `canChangePassword=false`는 입력/행동 없이 ‘비밀번호 로그인 계정이 아닙니다. 관리자에게 문의하세요.’를 보여준다.

## 시각 언어·합성 자료

HomeTheme와 Feather 선형 아이콘을 이어간다. 화이트/다크 그룹 표면, 얇은 경계, 절제된 파란 주 행동, 같은 제목/본문/메타 계층을 사용한다. 정책 안내는 짧게 묶되 4MB/2MB/투명 배경과 재로그인 영향을 숨기지 않는다. 프로토타입의 상태·테마·네트워크 제어는 **앱 화면 밖**에 둔다.

메인 **390×844 라이트**, 이예시·예시 부서·시설장·`yeseo@example.invalid`, 도장 **합성 ‘예시’ 등록 이미지**, 프로필 미등록, 비밀번호 변경 가능. 원본 기능 캡처는 이메일 미등록·두 이미지 미등록이라도 정상이다. 등록 도장은 실제 직원 인감/서명이 아닌 ‘예시’ 테스트 표식으로 명확히 한다.

추가: 360×800 다크, 긴 이름·부서·직급·이메일, 이메일 미등록, 두 이미지 등록/미등록, 도장/프로필 선택 저장 전·취소·다른 선택·저장 중/성공/실패·삭제 확인/취소/중/실패/완료, 미리보기 로딩/실패/재시도, 잘못된 파일·초과 크기·파일 선택 취소, 조회 로딩/처음 실패/새로고침 실패, 비밀번호 미입력·4자 미만·동일·불일치·현재 비밀번호 오류·네트워크 실패·중복 제출·성공 재로그인·변경 불가, 계정 전환/401/늦은 응답을 모의로 다룬다.

## 산출물과 완료 검수

완성된 **계정·도장 설정 v1** 페이지, 대표/주요 상태 캡처, 동작하는 검토용 프로토타입, 편집용 소스 ZIP **`bajaul-account-v1-source.zip`**, 검수 결과를 제공한다. 기존 일곱 페이지를 재작성하지 않는다.

- 390×844·360×800, 라이트/다크, 200% 상당 큰 글자에서 가로 넘침·겹침·행동 가림이 없어야 한다. 전체 폼을 스크롤로 접근할 수 있어야 한다.
- 최소 44px 행동, 논리적 제목·읽기 순서, visible focus, 일반 글자 4.5:1 대비, 보안 입력 이름과 오류, 확인창의 안전한 포커스를 검토한다.
- 내 정보 진입/뒤로·자식 화면 탭바 없음, 계정 읽기 전용·null 이메일, 도장→프로필→비밀번호 순서를 확인한다.
- 선택과 저장 구분, 취소/실패의 기존 이미지 및 입력 보존, 서버 확인 후 상태 확정, 삭제 확인, 작업 중 잠금·재시도·계정 이탈 후 늦은 응답 무시를 확인한다.
- 비밀번호 성공 모의 재로그인·변경 불가·첫 오류 포커스와 입력 보존을 확인한다.
- 검수한 크기·테마·상태·증거 경로를 기록한다. DOM/모의 상태 검토와 실제 OS 파일 선택·native 키보드/fontScale·VoiceOver/TalkBack·운영 API 검증을 구분하고 미확인은 그대로 적는다.

## 2026-10-06 실제 앱 반영

Claude Version 19 완료 시안은 `mobile/src/app/account.tsx`와 계정 전용 컴포넌트에 반영했다. 기능 계약·합성 검수 및 원본 출처는 `docs/design/mobile-account-v1/design-qa.md`와 `source.json`에 기록했다. 운영 배포는 별도 릴리스 기록으로 확인한다.
