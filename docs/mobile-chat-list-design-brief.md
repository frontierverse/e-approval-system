# 바자울 모바일 직원 채팅 목록 v1 디자인 브리프

기준: **2026-10-06 / 운영 main aa6fbc910868f3bf4a6c0506d002a996ac313d4b / 앱 업데이트 v1 반영 이후**. 기존 Claude 작업 **바자울 전자결재 앱 디자인**에 열 번째 페이지 **직원 채팅 목록 v1**을 추가한다. 홈 v2·문서함 v1·문서 상세 v1·기안 작성 v1·받은결재 v1·알림 v1·내 정보 v1·계정·도장 설정 v1·앱 업데이트 v1은 보존한다.

## 목적·범위

직원이 안 읽은 메시지와 최근 대화를 빠르게 확인하고, 이름·부서·직급으로 직원을 찾아 1:1 대화를 시작하게 한다. **내 정보 → 직원 채팅**(`/chat`)의 목록과 직원 찾기 상태만 이번에 디자인한다. 대화방(`/chat/[peerId]`)과 첨부 미리보기는 다음 작업이며, 클릭 후 목적지만 모의로 표시한다.

디자인·모의 프로토타입만 만든다. 실제 로그인·직원·메시지·파일·운영 API·앱 저장소·DB·소스·배포에 접근하거나 메시지를 보내지 않는다. 합성 자료만 사용하고 실제 앱 반영과 배포는 Codex가 진행한다. 새 컴퓨터 폴더나 권한 연결은 필요 없다.

첨부 01은 이 브리프, 02는 UI/UX 기준, 03은 최신 소스의 기능 계약, 04·05는 적용된 홈·내 정보 스타일이다. 현재 기능 캡처가 첨부되면 기존 구조 참고로만 사용한다. 최신 기능 계약이 기존 시안의 가정보다 우선한다.

## 구조와 시각 언어

Safe Area를 고려한 **뒤로 + 직원 채팅 + 새 대화**의 간결한 52px 안팎 헤더, **대화 수·안 읽은 메시지 수 → 대화 목록/직원 찾기 전환 → 검색 → 목록**으로 구성한다. 현재 nested stack 화면이므로 하단 탭바를 새로 만들지 않는다. 뒤로는 이전 화면, 이전 화면이 없으면 내 정보로 돌아가는 모의 동작이다.

두 상태를 선택형 44px 컨트롤로 명확히 구분하고, 새 대화는 직원 찾기를 선택하고 검색어를 비운다. 현재 코드에는 이름·부서·직급으로 두 목록을 필터링하는 로직이 있지만 검색란은 직원 찾기에서만 보인다. 이번에는 **두 목록 모두 검색란을 보이게** 하여 검색어가 남아 대화가 숨겨진 이유를 알 수 없게 되는 문제를 개선한다. 검색어는 전환할 때 유지하고 새 대화·검색 지우기에서만 비운다. 새 API·본문 검색·기간 필터를 추가하는 것이 아니다.

첫 실제 목록을 콘텐츠 상단 40% 이내에서 시작하도록 헤더·요약·컨트롤을 압축한다. 대화/안 읽음은 짧은 줄 또는 작은 요약 영역으로 표시하고 큰 KPI 카드·히어로·장식 채팅 일러스트·중복 설명을 넣지 않는다. 16px 바깥 여백·12~16px 의미 그룹 간격·얇은 경계·HomeTheme 라이트/다크·Feather 선형 아이콘을 기존 화면에서 이어간다. 긴 글자에서는 행 높이가 늘어나야 한다.

대화 목록은 **이름·최근 시각 → 마지막 메시지 미리보기·안 읽음 배지**의 간결한 행이다. 읽지 않은 수는 색과 숫자로 표시하고 이름/본문 굵기로 계층을 만든다. 서버가 제공한 최근 대화 순서를 유지한다. 직원 찾기는 **이름 → 부서·직급**을 우선하며 기존 대화가 있으면 실제 안 읽음 배지를 표시할 수 있다. 직원 사진·직원별 색·온라인·마지막 접속을 발명하지 않는다.

## 실제 데이터의 의미

- 상단 대화 수는 전체 대화 수, 안 읽음은 전체 **메시지** 수다. 현재 필터 결과 수와 구분한다. 결재 알림 수와 별개다.
- 0은 확인된 0건이다. 확인 중/실패는 0으로 바꾸지 않는다. 실패한 안 읽음 수는 **확인 필요**다.
- 배지는 1~99 실제 수, 100 이상 **99+**로 보이되 접근 이름에 실제 수를 제공한다. 총 안 읽음에는 실제 전체 수를 표시한다.
- 마지막 메시지 미리보기는 본문이 있으면 본문, 없으면 첨부파일명, 둘 다 없으면 **파일 메시지**다. 본문 검색은 지원하지 않는다.
- 시각은 기존 한국시간 월/일·24시간 시/분 형식을 유지한다. 오늘·어제 등 새 상대 날짜 규칙을 만들지 않는다.
- 비활성 직원의 기존 대화는 **기록** 상태로 열람할 수 있다. 직원 찾기에는 재직 직원만 나온다. 비활성 상대를 새 대화 가능/온라인으로 표현하지 않는다.
- 목록을 열거나 새로고침·검색하는 것만으로 읽음 처리되지 않는다. 목록의 읽음 버튼·모두 읽음·메시지 전송 버튼은 계약에 없다.

## 상태와 안전성

| 상태 | 표시와 행동 |
| --- | --- |
| 최초 확인/화면 재진입/앱 복귀 | 과거 이름·본문·건수 없이 **채팅 확인 중**과 최종 행 높이의 간결한 스켈레톤. 대화 선택·검색·새 대화 잠금. |
| 정상 대화 목록 | 확인된 요약·검색·서버 순서의 대화 행. 행을 눌러 해당 상대의 모의 목적지 표시. |
| 직원 찾기 | 같은 요약·전환·검색, 재직 직원 이름·부서·직급 행. 새 대화 누르면 여기로 이동하고 검색 초기화. |
| 대화 0건 | **아직 대화가 없습니다** + 짧은 안내 + 직원 찾기 행동 하나. |
| 재직 직원 0건 | **대화 가능한 직원이 없습니다**. 검색어 변경을 권하는 잘못된 안내 대신 현재 가능한 상대가 없음을 알림. |
| 검색 결과 0건 | **검색 결과가 없습니다** + 이름·부서·직급 검색 안내 + 검색 지우기. 전체 요약을 검색 결과 수로 바꾸지 않음. |
| 수동 새로고침 | 기존 내용을 먼저 가리고 확인 중, 중복 새로고침/목록 조작 잠금. |
| 최초/수동 확인 실패 | 이름·본문·건수를 노출하지 않고 실패 안내와 **다시 불러오기**. 실패를 정상 빈 목록으로 표현하지 않음. |
| 백그라운드 주기 갱신 실패 | 현재 검증된 계정·전경의 대화 목록은 남을 수 있지만 안 읽음 수는 **확인 필요**. 오류와 재시도. 인증/접근 실패로 요약이 제거되면 목록도 제거. |
| 비활성 직원 대화 | 이름에 **기록**, 접근 이름에 **현재 대화 기록만 확인 가능**. 기록 열람 목적지를 모의로 표시. |
| 앱 비활성/계정 변경/세션 만료 | 즉시 이전 사적 내용을 제거. 이전 응답으로 이름·본문·건수·화면 이동이 복원되지 않음. 앱 복귀는 새 조회 뒤에만 보여줌. |

새로고침은 명확한 접근 이름을 가진 44px 아이콘 또는 텍스트 행동으로 제공한다. 오류 재시도는 같은 조회를 재시도한다. 잠금은 보여주기만 하지 말고 실제 모의 핸들러도 막는다. 모의 새로고침을 연타해 중복 요청이 생기지 않게 한다. 프라이버시 확인 전에 행 선택으로 대화 화면이 열리면 안 된다.

앱의 모바일 채팅은 전경에서 5초 간격 HTTP 재조회다. 연결 상태나 다른 직원의 온라인 상태를 추측하지 않는다. 실시간 연결 설정·알림 토글·그룹 채팅·고정·숨기기·삭제·모두 읽음·채팅 파일 업로드를 목록 화면에 새로 넣지 않는다.

## 대표 자료와 산출물

메인 **390×844 라이트**, 대화 **4개**, 안 읽은 메시지 **7개**. 합성 상대 **김예시**(지원팀·담당, 3개), **이예시**(운영팀·팀장, 4개), **박예시**(사무팀·담당, 0개, 본문 없이 `회의자료_검수예시.pdf`), **정예시**(비활성, 기록, 0개). 마지막 시각은 한국시간 `10. 6. 09:40`부터 최근 순이며 본문은 ‘오늘 회의 자료 확인 부탁드립니다.’ 등 민감하지 않은 합성 내용만 사용한다. 직원 찾기에는 앞의 재직 3명과 대화 없는 **최예시**(지원팀·담당)를 넣는다.

추가 검토: 360×800 다크, 200% 상당 글자, 0/1/다수, 128개 배지, 긴 이름 `김아주긴이름예시직원`·긴 부서/직급·파일명, 양쪽 검색·전환·검색 지우기, 비활성 기록, 로딩·수동 새로고침·주기 갱신 실패·인증 만료·앱 복귀·계정 전환·늦은 응답·연타. 테마·모의 네트워크·계정·전경 컨트롤은 앱 화면 밖에 둔다.

**직원 채팅 목록 v1** 페이지, 대표/주요 상태 PNG, 동작하는 모의 프로토타입, 편집용 소스 ZIP **`bajaul-chat-list-v1-source.zip`**, 검수 결과와 미확인 항목을 제공한다. 대화방을 이 작업에서 새로 디자인하지 않는다.
